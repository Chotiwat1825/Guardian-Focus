# 🛡️ Guardian Focus - Chrome Extension

ส่วนขยายบนเบราว์เซอร์ Google Chrome ที่ทำงานร่วมกับเว็บแอปพลิเคชัน **Reading Time (ตัวจับเวลาการอ่านหนังสือ)** เพื่อช่วยบล็อกหน้าเว็บบันเทิงอื่นๆ และป้องกันการหลุดโฟกัสระหว่างการศึกษาหรือทำงาน

---

## ✨ คุณสมบัติหลัก (Key Features)

*   **🚫 บล็อกเว็บไซต์ที่ไม่อนุญาต (Site Blocker)**: เมื่อเปิดใช้งานโหมดโฟกัส ระบบจะบล็อกการเข้าใช้เว็บไซต์ที่ไม่ได้อยู่ในรายชื่อที่อนุญาตโดยอัตโนมัติ
*   **⏳ ระบบนับถอยหลังเตือนตัว (Distraction Countdown)**: หากสลับไปหน้าเว็บอื่นที่ไม่อนุญาต ระบบจะนับถอยหลังเตือน (เช่น 10 วินาที) ก่อนจะสั่งบังคับสลับไปโหมดพักผ่อนบนเว็บแอปหลัก
*   **🎮 ระบบสั่นจอยเตือนเชิงรุก (Haptic Vibration Warning)**: มอเตอร์สั่นของจอยเกม (Gamepad) จะสั่นสะกิดเตือนทุกวินาทีในระหว่างที่ระบบกำลังนับถอยหลังบล็อกหน้าเว็บเพื่อเรียกสติผู้ใช้
*   **📝 จัดการรายชื่อเว็บที่ปลอดภัยได้อิสระ (Custom Allowed List)**: ปรับแต่ง เพิ่ม หรือลบเว็บไซต์ที่ต้องการอนุญาตให้อ่านหนังสือได้โดยตรงผ่านป็อปอัปของส่วนขยาย
*   **🔄 ซิงค์ข้อมูลสองทางเรียลไทม์ (Bidirectional Real-time Sync)**: รับส่งสถานะการจับเวลาและระยะเวลานับถอยหลังเตือนที่ผู้ใช้ตั้งค่าไว้จากเว็บแอป Reading Time โดยอัตโนมัติ
*   **🇹🇭 รองรับภาษาไทยสมบูรณ์แบบ**: ใช้ฟอนต์ Sarabun สวยงาม อ่านง่าย เป็นระเบียบ

## 🚀 คู่มือวิธีการติดตั้งอย่างละเอียด (Installation Guide)

เนื่องจากส่วนขยายนี้ยังไม่ได้อัปโหลดขึ้น Chrome Web Store คุณจำเป็นต้องติดตั้งในฐานะผู้พัฒนา (Developer Mode) ตามขั้นตอนดังนี้:

1.  **เตรียมโฟลเดอร์ส่วนขยาย**:
    *   ดาวน์โหลดไฟล์หรือโคลนโปรเจกต์นี้มาไว้ในเครื่องคอมพิวเตอร์ของคุณ (เช่น `C:\Users\Admin\Desktop\Code\Extensions\Guardian Focus`)
2.  **เปิดหน้าจัดการส่วนขยายของ Chrome**:
    *   เปิดเบราว์เซอร์ Google Chrome
    *   พิมพ์ `chrome://extensions/` ที่ช่องกรอก URL ด้านบนแล้วกด Enter (หรือไปที่ **เมนูสามจุด (ขวาบน) -> ส่วนขยาย (Extensions) -> จัดการส่วนขยาย (Manage Extensions)**)
3.  **เปิดโหมดนักพัฒนา (Developer Mode)**:
    *   เปิดสวิตช์ **โหมดนักพัฒนา (Developer mode)** ที่บริเวณมุมบนขวาของหน้าจอให้เป็น **เปิด (On)**
4.  **โหลดโฟลเดอร์ส่วนขยาย**:
    *   คลิกปุ่ม **โหลดส่วนขยายที่คลายการบีบอัดแล้ว (Load unpacked)** ที่มุมบนซ้ายของหน้าจอ
    *   เลือกโฟลเดอร์ `Guardian Focus` ที่คุณเตรียมไว้ในข้อ 1 แล้วคลิกตกลง (Select Folder)
5.  **เสร็จสิ้นการติดตั้ง**:
    *   ส่วนขยายจะแสดงขึ้นมาในหน้าต่างพร้อมใช้งาน
    *   แนะนำให้คลิกไอคอนจิ๊กซอว์ 🧩 ที่มุมขวาบนของ Chrome แล้วกดไอคอน **หมุด (Pin)** ข้างส่วนขยาย **Guardian Focus** เพื่อความสะดวกในการติดตามสถานะการเปิด/ปิดระบบป้องกัน

## 🛠️ หลักการทำงานร่วมกับเว็บแอปพลิเคชัน (How It Works)

ส่วนขยายสื่อสารกับหน้าเว็บแอปพลิเคชันหลัก (`Reading Time`) ผ่านช่องทางความปลอดภัย `window.postMessage` โดยส่งต่อสถานะดังนี้:

*   **GuardianPing / GuardianPong**: ตรวจสอบสถานะการเชื่อมต่อระหว่างหน้าเว็บหลักและ Extension
*   **SET_TIMER_STATE**: ซิงก์เวลานับถอยหลังสิ้นสุดเซสชัน, สถานะการจับเวลา (กำลังเดิน/หยุดนิ่ง), และโหมดที่ใช้ (โฟกัส/พักเบรก)
*   **SET_WARNING_SECONDS**: กำหนดเวลานับถอยหลังเตือนวินาทีสูงสุดก่อนบังคับพัก ซึ่งผู้ใช้งานสามารถปรับเปลี่ยนได้ตามใจชอบจากหน้าการตั้งค่าหลักในเว็บแอป
*   **SET_BREAK_MODE**: ปลดล็อกการบล็อกเว็บชั่วคราวโดยอัตโนมัติเมื่อผู้ใช้เข้าสู่ช่วงเวลาพักเบรก (Break Mode) และล็อกเว็บอีกครั้งเมื่อเริ่มอ่านหนังสือรอบถัดไป
